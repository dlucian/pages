Vitrina · roadmap · 29 Aug 2026

The shop window learns to look back

Vitrina already runs the whole trip from mined idea to published post across seven channels. Compared against Typefully, Hypefury, Buffer, and Postiz, exactly one structural gap shows up:

Vitrina knows what went out — but never learns what happened next.

Tier 1 · build next

Close the feedback loop

Every serious tool in the space closes this loop; Hypefury's two most-loved features both depend on it. All three ideas below feed on data Vitrina already stores.

Outcome capture

Seven days after a posting, Today grows a "check results" entry. You (or Ezri, via Firecrawl or the HN API) record a small metrics blob on the posting row. One nullable JSON column, one due-date rule.

Analytics screen

Conversion through the pipeline, median time-in-state, posts per week per channel — all derivable from dates already in the database. Once outcomes exist: hit rate by channel, tag, and title pattern.

Evergreen recycling

A published card older than six months becomes eligible for a "revive" queue proposing a fresh variation — new ordinal, same or new channel. Proven material, zero schema change. Hypefury's core retention trick.

Tier 2 · high value, low drama

Less friction, healthier pool

Four smaller pieces. Each one removes a paper cut from the daily ritual or keeps the growing card pool navigable.

Best posting window, title conventions, and format quirks rendered on each Today entry — the Medium and HN timing research encoded where it gets used, not in a note nobody reopens.

"Copy text" plus a pre-filled intent URL per channel — X web intent, LinkedIn share dialog. Posting stays manual and deliberate; the taps halve.

Full-text search

SQLite FTS5 across titles, pitches, bodies, variation text, and evidence. Tag filtering works at 50 cards; it will not at 500. The index is built into SQLite — no new infrastructure.

Tier 3 · when the trigger fires

Parked, with named triggers

Deliberately not scheduled. Each has the condition that un-parks it, so nothing needs re-deciding later.

Quick capture from the phone

A share-sheet or Telegram-to-card path. Ezri can already file cards via the API — this makes it a standing convention.

What Vitrina refuses to become

The comparison tools carry features that would make Vitrina worse, not rounder.

Auto-posting

API cost and fragility, against the spec's "nothing posts on Lucian's behalf" — and the manual ritual is the quality gate.

Teams, approvals, inbox

Buffer and Mixpost features for agencies. Vitrina has one user behind a tailnet.

In-app AI drafting

Drafting already has an owner — Ezri, through the same API the app uses. A button would duplicate a working path.
